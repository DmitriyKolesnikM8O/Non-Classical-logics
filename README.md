# Комплексное практическое занятие по курсу «Неклассические логики»

**Тема:** Моделирование нечетких величин и кластерный анализ множества нечетких величин  
**Вариант:** 1 — Равномерное распределение

## 1. Постановка задачи

Разработать программный комплекс на языке Python, состоящий из независимой библиотеки и графического пользовательского интерфейса (GUI), обеспечивающий:
1. Моделирование нечетких величин с **равномерным распределением** (прямоугольной функцией принадлежности вида μ(x) = 1 при x ∈ [a, b]).
2. Выполнение базовых операций манипулирования нечеткими величинами: сложение, вычитание, умножение, деление, сравнение (ранжирование), вычисление метрик расстояния.
3. Генерацию случайной выборки нечетких величин в количестве от 100 до 300 элементов.
4. Проведение процедуры кластерного анализа множества нечетких величин:
   - на заданное число кластеров K;
   - по заданному критерию (пороговое внутрикластерное расстояние / плотность).
5. Журналирование всех действий и операций в файл-лог с метками времени.
6. Интерактивную визуализацию операций, функций принадлежности и результатов кластеризации в GUI.
7. Оформление программной документации и модульной структуры для использования сторонними программами.

## 2. Теоретическая модель (Вариант 1: Равномерное распределение)

Нечеткая величина равномерного типа задается парой граничных параметров `[a, b]`, где `a ≤ b`.

### 2.1. Функция принадлежности

```text
        ⎧ 1,  если a ≤ x ≤ b
μ(x) = ⎨
        ⎩ 0,  если x < a или x > b
```

**α-срез величины** `A_α = {x : μ(x) ≥ α}`. У равномерной `μ` он не зависит от
уровня (`A_α = [a, b]` при любом `0 < α ≤ 1`), поэтому «уровень отбора» в
программе применяется к отношению сходства между величинами (см. п. 4).

Для сравнения в библиотеке есть общие формулы среза: `alpha_cut_trapezoid(a, c, d, b, alpha)`
и `alpha_cut_triangular(a, m, b, alpha)`. Равномерная `μ` — вырожденная трапеция
с `c = a`, `d = b`, поэтому обе функции дают `[a, b]`.

### 2.2. Числовые характеристики величины

- **Модальный центр (центроид):**  
  `c = (a + b) / 2`
- **Ширина носителя:**  
  `w = b - a`

### 2.3. Арифметические операции (принцип обобщения Заде / интервальная арифметика)

Для двух нечетких величин `A = [a₁, b₁]` и `B = [a₂, b₂]`:

- **Сложение:**
  ```text
  [a₁, b₁] + [a₂, b₂] = [a₁ + a₂, b₁ + b₂]
  ```

- **Вычитание:**
  ```text
  [a₁, b₁] - [a₂, b₂] = [a₁ - b₂, b₁ - a₂]
  ```

- **Умножение:**
  ```text
  [a₁, b₁] · [a₂, b₂] = [min(P), max(P)]
  где P = { a₁·a₂, a₁·b₂, b₁·a₂, b₁·b₂ }
  ```

- **Деление:**
  ```text
  [a₁, b₁] / [a₂, b₂] = [a₁, b₁] · [1/b₂, 1/a₂]   (при условии 0 ∉ [a₂, b₂])
  ```

### 2.4. Метрики расстояния и сравнение

- **Евклидово расстояние между границами:**
  ```text
  d(A, B) = √[ ((a₁ - a₂)² + (b₁ - b₂)²) / 2 ]
  ```

- **Метрика Хаусдорфа:**
  ```text
  d_H(A, B) = max( |a₁ - a₂|, |b₁ - b₂| )
  ```

- **Сравнение (ранжирование):**  
  Сравнение величин производится по модальному центру `c`, ширине интервала `w` и степени доминирования (вероятности превышения).

## 4. Подробный пошаговый план реализации

### Этап 1. Разработка ядра библиотеки (`src/fuzzy_core/`)
- [x] **1.1. Класс `UniformFuzzyVariable`:**
  - Хранение границ [a, b], проверка корректности (a ≤ b);
  - Вычисление свойств: ядро, носитель, центр c, ширина w, значение μ(x);
  - Перегрузка операторов `+`, `-`, `*`, `/` в соответствии с интервальной арифметикой Заде;
  - Защита от деления на интервал, содержащий 0;
  - Методы сравнения (`==`, `<`, `>`, степень строгого предпочтения);
  - Функции вычисления расстояний (евклидово между границами, Хаусдорф).
- [x] **1.2. Класс `FuzzySet`:**
  - Коллекция нечетких величин, операции добавления, удаления, фильтрации, поиска.
- [x] **1.3. Генератор выборки (`generator.py`):**
  - Генерация случайного набора от 100 до 300 величин с настраиваемыми диапазонами;
  - Поддержка сида генератора случайных чисел для воспроизводимости.
- [x] **1.4. Модуль кластерного анализа (`clustering.py`):**
  - **Кластеризация на K кластеров:** алгоритм K-Means, адаптированный под нечеткие интервалы (с пересчетом центроидов как средних значений границ);
  - **Кластеризация по критерию:** пороговая кластеризация (объединение элементов с расстоянием меньше заданного порога ε);
  - **Кластеризация по α-уровню:** α-срез отношения сходства `r_ij = 1 − d_ij/d0` — уровень отбора α ∈ (0, 1], от которого зависит число кластеров (компоненты связности α-среза, max-min замыкание, профиль k(α));
  - **Движок `AlphaClusterer`** — тяжёлые матрицы (сходство, замыкание, трасса агломерации) считаются один раз, поэтому перебор уровней α стоит доли миллисекунды; `Agglomeration` даёт разрез дендрограммы при любом пороге;
  - **Пошаговая агломерация:** `Agglomeration.steps()`/`labels_after(step)` позволяют «проиграть» процесс полной связи слияние за слиянием; функция `agglomerate()` строит трассу, `grouped_result()` собирает результат по готовым меткам;
  - Расчет статистик качества кластеризации (внутрикластерные дисперсии, диаметры кластеров).

### Этап 2. Подсистема журналирования (`src/logger/`)
- [x] **2.1. Модуль `session_logger.py`:**

### Этап 3. Графический интерфейс пользователя (`src/gui/`)
- [x] **3.1. Разработка экранной формы (Tkinter):**
  - **Вкладка «Арифметика нечетких величин»:** интерактивный калькулятор с вводом величин A и B, выбором операции (+, -, *, /, сравнение), текстовым протоколом и графиком функций принадлежности;
  - **Вкладка «Генерация и выборка»:** задание параметров выборки (100–300 элементов), отображение сгенерированного списка в виде таблицы;
  - **Вкладка «Кластерный анализ»:** выбор метода (на K кластеров, по порогу, по α-уровню или по плотности), запуск анализа, отображение результатов по кластерам и 2D-диаграммы рассеяния кластеров с профилем k(α);
  - **Интерактивный α-уровень:** ползунок α пересчитывает кластеры на лету (кнопка `▶` «проигрывает» уровни), а результат показан на трёх вкладках — диаграмма, кривая `k(α)` и тепловая карта матрицы сходства с подсветкой α-среза;
  - **Пошаговая агломерация:** для метода «по порогу» кнопки `Шаг`/`▶`/`↺` и ползунок скорости показывают процесс полной связи слияние за слиянием (счётчик шагов, обновление диаграммы и таблиц, запись каждого шага в журнал);
  - **Вкладка «Журнал (Лог)»:** просмотр актуального лога сессии с возможностью сохранения в файл.

### Основные команды

| Что сделать | Команда |
| --- | --- |
| Запустить программу | `.venv\Scripts\python.exe main.py` |
| Запустить с другой папкой журналов | `.venv\Scripts\python.exe main.py --log-dir D:\logs` |
| Прогнать тесты | `.venv\Scripts\python.exe -m pytest` |
| Собрать документацию в Word | `.venv\Scripts\python.exe docs\build_docx.py` |

Итоговый документ собирается из семи разделов папки `docs/` в один файл Word;
титульный лист берётся из `docs/Титульник.docx` и вставляется автоматически
(ключ `--no-title-page` отключает его). Содержание — настоящее поле TOC Word:
при открытии документа Word сам подставляет разделы и номера страниц, поле можно
обновить через `F9`. Если нужен простой список заголовков без обновления полей,
используйте `--toc text`; ключ `--toc none` собирает документ без содержания.
