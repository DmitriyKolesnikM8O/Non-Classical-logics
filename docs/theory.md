# Теоретический раздел

Документ описывает математическую модель, на которой построена программа:
нечеткие величины с равномерной функцией принадлежности (вариант 1 задания),
арифметику по принципу обобщения Заде, метрики расстояния, правила сравнения,
генерацию выборки, алгоритмы кластерного анализа и оценки его качества.

Все формулы приведены ровно в том виде, в котором они реализованы в библиотеке
`fuzzy_core`, а числовые примеры посчитаны самой программой.

---

## 1. Нечеткая величина с равномерной функцией принадлежности

### 1.1. Определение

Нечеткая величина варианта 1 задаётся парой граничных параметров `[a, b]`,
где `a ≤ b`, и описывается функцией принадлежности

```text
        ⎧ 1,  если a ≤ x ≤ b
μ(x) =  ⎨
        ⎩ 0,  если x < a или x > b
```

Такую функцию принадлежности называют равномерной: внутри отрезка `[a, b]`
все значения равновозможны (принадлежность максимальная), вне отрезка —
невозможны. Носителем величины служит отрезок `[a, b]`, ядром — тоже `[a, b]`
(в отличие, например, от треугольной величины, где ядро — одна точка).

Если `a = b`, величина называется **вырожденной** (точечной): она выражает
обычное, «чёткое» число `a`, но по-прежнему участвует в операциях по правилам
интервальной арифметики.

### 1.2. Числовые характеристики

- **Модальный центр (центроид):**

  ```text
  c = (a + b) / 2
  ```

- **Ширина носителя:**

  ```text
  w = b − a,   w ≥ 0
  ```

По этим двум числам величина восстанавливается однозначно:
`a = c − w/2`, `b = c + w/2`. Поэтому пару `(c, w)` удобно использовать как
координаты точки на плоскости — именно так строится диаграмма рассеяния
кластеров в интерфейсе программы: по горизонтали центр `c`, по вертикали
ширина `w`.

### 1.3. Пример

```text
A = [1, 3]  →  c = 2.0,   w = 2.0
B = [2, 5]  →  c = 3.5,   w = 3.0
```

## 2. Арифметические операции (принцип обобщения Заде)

### 2.1. Принцип обобщения

Пусть `A = [a₁, b₁]` и `B = [a₂, b₂]` — нечеткие величины, `∗` — одна из
арифметических операций. Согласно принципу обобщения Заде результат операции
есть нечеткая величина с функцией принадлежности

```text
μ_C(z) = max{ min( μ_A(x), μ_B(y) ) : z = x ∗ y }
```

Для величин с равномерной функцией принадлежности (μ = 1 на отрезке, 0 вне
его) этот принцип даёт классическую **интервальную арифметику**: результатом
операции снова является отрезок, границы которого получаются из границ
операндов.

### 2.2. Формулы операций

```text
Сложение:    [a₁, b₁] + [a₂, b₂] = [a₁ + a₂,  b₁ + b₂]

Вычитание:   [a₁, b₁] − [a₂, b₂] = [a₁ − b₂,  b₁ − a₂]

Умножение:   [a₁, b₁] · [a₂, b₂] = [min P,  max P],
             где P = { a₁a₂, a₁b₂, b₁a₂, b₁b₂ }

Деление:     [a₁, b₁] / [a₂, b₂] = [a₁, b₁] · [1/b₂, 1/a₂],
             если 0 ∉ [a₂, b₂]
```

Смысл перебора четырёх произведений при умножении: минимум и максимум
произведения двух независимых чисел достигаются на концах отрезков, поскольку
произведение линейно по каждому аргументу.

Умножение (и деление) на обычное число `k` выполняется как операция с
вырожденной величиной `[k, k]`.

### 2.3. Особые случаи

1. **Деление на интервал, содержащий нуль.** Если `0 ∈ [a₂, b₂]`, частное не
   определено (внутри делителя есть сколь угодно близкое к нулю значение), и
   библиотека возбуждает исключение `FuzzyVariableError` с сообщением вида
   «Деление невозможно: интервал делителя [-1, 1] содержит 0». Проверяются оба
   случая: нуль внутри отрезка и нуль на его границе.
2. **Вырожденные величины.** Точечные величины `[k, k]` обрабатываются общими
   формулами; например, `[1, 3] · 2 = [2, 6]`.
3. **Знаки.** Формулы не требуют положительности: отрицательные интервалы
   (например, `[-7, -2]`) обрабатываются теми же правилами. Это важно, так как
   генератор выборки выдаёт величины с центрами от −10 до 10.

### 2.4. Пример

```text
A = [1, 3],  B = [2, 5]

A + B = [1 + 2, 3 + 5]           = [3, 8]
A − B = [1 − 5, 3 − 2]           = [−4, 1]
A · B = [min{2, 5, 6, 15}, max]  = [2, 15]
1/B   = [1/5, 1/2]               = [0.2, 0.5]
A / B = [min{0.2, 0.5, 0.6, 1.5}, max] = [0.2, 1.5]
```

### 2.5. Свойства

- Сложение и умножение коммутативны и ассоциативны; вычитание и деление — нет:
  `B − A = [−1, 4]` в том же примере.
- Ширины при сложении и вычитании складываются: `w(A ± B) = w(A) + w(B)`
  (для примера: `w(A − B) = 5 = 2 + 3`).
- Операции сохраняют включение: если `A ⊆ A'`, то `A ∗ B ⊆ A' ∗ B`.

## 3. Метрики расстояния

Расстояние между величинами нужно для сравнения, поиска ближайших элементов и
для всех алгоритмов кластеризации. В библиотеке реализованы две метрики.

### 3.1. Метрика Хаусдорфа (основная)

```text
d_H(A, B) = max( |a₁ − a₂|, |b₁ − b₂| )
```

Это расстояние между отрезками как между множествами: насколько далеко друг от
друга отстоят самые «разошедшиеся» точки. Метрика показывает, на сколько нужно
«раздвинуть» один интервал, чтобы он накрыл другой.

В координатах `(c, w)`, где `Δc = c₁ − c₂` и `Δw = w₁ − w₂`:

```text
d_H = max( |Δc − Δw/2|,  |Δc + Δw/2| )
```

то есть расстояние определяется и сдвигом центров, и разницей ширин.

### 3.2. Евклидово расстояние между границами

```text
d_E(A, B) = √( ((a₁ − a₂)² + (b₁ − b₂)²) / 2 )
```

Деление на 2 оставляет масштаб сопоставимым с метрикой Хаусдорфа: для
одинаково сдвинутых интервалов `d_E = |сдвиг|`, если ширины равны.

### 3.3. Пример

```text
A = [1, 3],  B = [2, 5]

d_H(A, B) = max(|1 − 2|, |3 − 5|) = max(1, 2) = 2.0
d_E(A, B) = √((1 + 4) / 2) = √2.5 ≈ 1.5811
```

### 3.4. Свойства и выбор метрики

Обе метрики являются метриками в математическом смысле: неотрицательны,
равны нулю только для совпадающих величин, симметричны и удовлетворяют
неравенству треугольника.

Метрика Хаусдорфа «жёстче»: она чувствует сильное расхождение хотя бы с одной
стороны. Евклидова усредняет расхождение по обеим границам. По умолчанию в
программе используется метрика Хаусдорфа; метрику можно переключить в интерфейсе
и в вызовах библиотеки, все алгоритмы кластеризации работают с выбранной
метрикой.

## 4. Сравнение нечетких величин

Обычные числа сравниваются однозначно, а нечеткие величины могут пересекаться,
поэтому для них применяют индексы нечеткого сравнения и правило упорядочивания.

### 4.1. Индексы возможности и необходимости (Заде)

```text
Pos(A ≥ B) = 1, если b₁ ≥ a₂, иначе 0
Nec(A ≥ B) = 1, если a₁ ≥ b₂, иначе 0
```

- `Pos(A ≥ B) = 1` означает, что **возможно** (хотя бы в одной точке) значение
  `A` не меньше значения `B`; равенство нулю — что это невозможно ни при каком
  выборе значений.
- `Nec(A ≥ B) = 1` означает, что `A` не меньше `B` **при любом** выборе
  значений внутри носителей, то есть превосходство достоверно.

Для интервалов выполняется `Nec(A ≥ B) ⇒ Pos(A ≥ B)`.

### 4.2. Степень доминирования

Индексы возможности и необходимости принимают только значения 0 и 1, поэтому
дополнительно вычисляется **степень доминирования** — вероятность того, что
случайное значение величины `A` превзойдёт случайное значение `B`:

```text
Dom(A, B) = P(X_A > X_B),  X_A ~ U[a₁, b₁],  X_B ~ U[a₂, b₂]
```

Величины трактуются как независимые и равномерно распределённые на своих
носителях (что естественно для равномерной функции принадлежности). Величина
`Dom(A, B)` лежит в `[0, 1]` и:

- равна 0, если `b₁ ≤ a₂` (величина `A` заведомо не больше);
- равна 1, если `a₁ ≥ b₂` (величина `A` заведомо больше);
- равна 0.5 для совпадающих вырожденных величин;
- дополняет обратную вероятность: `Dom(A, B) + Dom(B, A) = 1`, так как событие
  `X_A = X_B` для непрерывных распределений имеет нулевую вероятность (случай
  двух одинаковых вырожденных величин даёт 0.5 + 0.5 = 1).

Реализация использует замкнутую формулу. Обозначим `w₁ = b₁ − a₁`,
`w₂ = b₂ − a₂` и `[x]⁺ = max(x, 0)`. Тогда для невырожденных величин

```text
        [b₁ − a₂]⁺² − [a₁ − a₂]⁺² − [b₁ − b₂]⁺² + [a₁ − b₂]⁺²
Dom =  ─────────────────────────────────────────────────────────
                            2 · w₁ · w₂
```

Частные случаи: если `A` вырождена, `Dom = [(a₁ − a₂)/w₂]` с ограничением в
`[0, 1]`; если вырождена `B`, `Dom = [(b₁ − a₂)/w₁]`.

### 4.3. Правило упорядочивания

Для ранжирования (сортировки) величин используется лексикографический порядок
по паре `(c, w)`:

```text
A < B  ⇔  (c₁ < c₂)  или  (c₁ = c₂ и w₁ < w₂)
```

Смысл: сначала сравниваются модальные центры, а при их равенстве — ширины.
Более узкая величина при равном центре считается «меньшей» (она точнее
локализована и в этом смысле слабее перекрывает другие значения). Такое правило
задаёт полный детерминированный порядок, удобный для сортировки таблиц и
устойчивый к перестановкам элементов.

### 4.4. Пример

```text
A = [1, 3],  B = [2, 5]

Pos(A ≥ B) = 1   (так как b₁ = 3 ≥ a₂ = 2)
Nec(A ≥ B) = 0   (так как a₁ = 1 < b₂ = 5)
Dom(A, B)  = (1² − 0 − 0 + 0) / (2 · 2 · 3) = 1/12 ≈ 0.0833
Dom(B, A)  ≈ 0.9167
A < B            (2 < 3.5 по центрам)
```

Проверка `Dom` методом Монте-Карло (200 000 пар) даёт 0.0835 — совпадение с
формулой.

## 5. Генерация выборки

Выборка формируется следующим образом:

```text
a ~ U(-10, 10)          левая граница
w ~ U(0, 4)             ширина носителя
b = a + w               правая граница (автоматически a ≤ b)
N ~ U{100, …, 300}      объём выборки
```

Объём выборки по заданию лежит в диапазоне от 100 до 300 величин; конкретное
значение выбирается случайно, если не задано явно. Все диапазоны
(`a_range`, `width_range`, `count_range`) можно переопределить.

Свойства получаемой выборки:

- левая граница равномерна на `[-10, 10]`, поэтому центры `c = a + w/2`
  сосредоточены около нуля, а ширины `w` — на `[0, 4]` со средним 2;
- величины могут пересекаться, что делает задачу кластеризации содержательной:
  кластеры выделяются по совместному расположению центров и ширин;
- вырожденные величины возможны, но маловероятны (нужна ровно нулевая ширина).

**Воспроизводимость.** Генератор использует собственный источник случайных
чисел; при одинаковых параметрах и заданном `seed` выборка полностью
воспроизводима: то же зерно даёт тот же набор величин. Если зерно не задано, оно
выбирается случайно и записывается в журнал, поэтому любой эксперимент можно
повторить по журналу.

## 6. Кластерный анализ

### 6.1. Постановка задачи

Объектами кластеризации являются нечеткие величины `X₁, …, X_N`; расстояние
между ними задаётся выбранной метрикой (по умолчанию Хаусдорфа). Требуется
разбить набор на группы так, чтобы внутри группы величины были близки, а между
группами — далеки. В программе реализованы три подхода:

1. кластеризация на заданное число кластеров `K` (K-Means);
2. кластеризация по критерию — по порогу внутрикластерного расстояния;
3. кластеризация по плотности (DBSCAN-подобная).

**Центроид кластера** — величина со средними границами его элементов:

```text
a_центр = (Σ a_i) / m,   b_центр = (Σ b_i) / m,   m — размер кластера
```

Такой центроид минимизирует сумму квадратов евклидовых расстояний между
границами, то есть является «средней величиной» кластера; для метрики Хаусдорфа
он используется как естественная приближённая оценка центра.

Во всех алгоритмах кластеры нумеруются детерминированно: по возрастанию центра
центроида, а при равенстве — по возрастанию его ширины. Это значит, что при
повторном запуске с теми же данными номера кластеров не меняются, и результаты
удобно сравнивать между запусками.

### 6.2. Кластеризация на K кластеров (K-Means)

Классический итеративный алгоритм, адаптированный под нечеткие величины:

1. **Инициализация** — выбор `K` начальных центроидов по схеме k-means++:
   первый центроид выбирается случайно, каждый следующий — случайно с
   вероятностью, пропорциональной квадрату расстояния до ближайшего из уже
   выбранных. Это резко снижает вероятность неудачного начального разбиения.
2. **Отнесение** — каждая величина относится к кластеру с ближайшим центроидом
   (при равных расстояниях — к кластеру с меньшим номером, что обеспечивает
   детерминированность).
3. **Пересчёт** — центроид каждого кластера заменяется средней величиной его
   элементов.
4. **Останов** — шаги 2–3 повторяются, пока максимальное изменение границ
   любого центроида не станет меньше `tol`, либо пока не выполнено `max_iter`
   итераций (по умолчанию 100).

**Специальный случай — пустой кластер.** Если после шага отнесения некоторый
кластер остался без элементов, в него переносится точка, наиболее удалённая от
своего центроида, взятая из кластера, где элементов больше одного. Это
стандартный приём, не позволяющий алгоритму «терять» кластер и возвращать
меньше `K` групп.

Алгоритм завершается за конечное число итераций: число различных разбиений
набора на `K` групп конечно. При евклидовой метрике пересчёт центроида как
средней величины уменьшает сумму квадратов расстояний, поэтому процесс
монотонно сходится к локальному минимуму. При метрике Хаусдорфа центроид
является приближённой оценкой центра, и монотонность убывания не гарантируется;
остановка происходит по стабилизации центроидов (`tol`) либо по исчерпанию
лимита итераций (`max_iter`). Результат зависит от начальной инициализации,
поэтому зерно генератора влияет на разбиение; при заданном зерне результат
воспроизводим.

Ограничения параметров: `1 ≤ K ≤ N`, `max_iter ≥ 1`, `tol ≥ 0`.

### 6.3. Кластеризация по критерию (порог, полная связь)

Агломеративный алгоритм: сначала каждая величина — отдельный кластер, затем
кластеры последовательно объединяются, начиная с самых близких. Критерий
объединения — **полная связь** (maximum linkage): два кластера сливаются,
только если **максимальное** расстояние между их элементами не превышает
порога `threshold`.

```text
слить C₁ и C₂  ⇔  max{ d(x, y) : x ∈ C₁, y ∈ C₂ } ≤ threshold
```

Выбор полной связи, а не одиночной, принципиален: при одиночной связи
(когда достаточно близости одной пары точек) возникает «цепной эффект» —
последовательность близких элементов стягивает в один кластер почти весь
набор. Полная связь требует близости **всех** пар, поэтому кластеры получаются
компактными, а их число определяется данными и порогом, а не задаётся заранее.

Реализация использует матрицу расстояний и приоритетную очередь пар кластеров:
после каждого слияния достаточно пересчитать расстояния до нового кластера.
Алгоритм останавливается, когда минимальное из оставшихся расстояний по полной
связи превышает порог. Чем больше `threshold`, тем крупнее кластеры; при очень
малом пороге (например, 0.1 при разбросе центров в единицы) получаются
преимущественно кластеры из одной величины.

### 6.4. Кластеризация по плотности (DBSCAN-подобная)

Идея: кластер — это область высокой плотности, разделённая областями низкой
плотности. Параметры: радиус `eps > 0` и минимальное число точек
`min_points ≥ 1`.

- точка **ядровая**, если в радиусе `eps` от неё (включая её саму) находится не
  менее `min_points` точек;
- кластер строится из ядровых точек: от ядровой точки выполняется обход всех
  её соседей, а от каждого ядрового соседа — дальше;
- **граничные** точки (не ядровые, но попавшие в радиус ядровой) включаются в
  кластер, но расширение через них не продолжается;
- точки, не достижимые ни из какой ядровой точки, объявляются **шумом** и
  получают метку `−1`; на графике они рисуются серым.

Отличия от классического DBSCAN: граничная точка, достижимая из двух разных
кластеров, попадает в тот, который обойдён раньше (порядок обхода определяется
порядком элементов); число кластеров заранее неизвестно и определяется
данными. Плотностная кластеризация хорошо выделяет кластеры произвольной формы
и честно помечает выбросы, но чувствительна к выбору `eps`: слишком малый
радиус переводит большинство точек в шум, слишком большой — объединяет всё в
один кластер.

### 6.5. Сравнение методов

```text
Метод          Что задаётся        Число кластеров   Особенность
─────────────────────────────────────────────────────────────────────────────
K-Means        число K            ровно K           сферичные кластеры,
                                                    зависит от инициализации
По порогу      порог расстояния   определяется       компактные кластеры,
                                  данными           нет «цепного эффекта»
По плотности   eps, min_points    определяется       выделяет шум,
                                  данными           произвольная форма
```

## 7. Оценки качества кластеризации

Для любого из трёх методов вычисляются следующие характеристики.

### 7.1. Характеристики отдельного кластера

- **Размер** `m` — число элементов кластера.
- **Диаметр** — максимальное расстояние между элементами кластера:

  ```text
  D(C) = max{ d(x, y) : x, y ∈ C }
  ```

- **Инерция** — сумма квадратов расстояний элементов до центроида:

  ```text
  I(C) = Σ d(x, центроид C)²
  ```

- **Внутрикластерная дисперсия центров** — дисперсия модальных центров
  элементов кластера (генеральная дисперсия выборки из `m` значений):

  ```text
  V(C) = (1/m) Σ (c_i − c̄)²,   c̄ = (1/m) Σ c_i
  ```

### 7.2. Сводные характеристики

- **Суммарная инерция** `I = Σ I(C)` — целевая функция K-Means; чем меньше,
  тем компактнее кластеры относительно своих центроидов.
- **Средняя внутрикластерная дисперсия** `V = (1/K) Σ V(C)` — насколько узко
  сгруппированы центры внутри кластеров.
- **Максимальный диаметр** `max D(C)` — самая «размазанная» группа.

### 7.3. Коэффициент силуэта

Силуэт оценивает, насколько каждый элемент «свой» в своём кластере по
сравнению с ближайшим чужим кластером:

```text
для элемента i:  a(i) — среднее расстояние до элементов своего кластера,
                 b(i) — наименьшее среднее расстояние до элементов другого
                        кластера,
                 s(i) = (b(i) − a(i)) / max(a(i), b(i))
```

Коэффициент силуэта — среднее `s(i)` по всем элементам (без шумовых точек):

```text
S = (1/n) Σ s(i)      −1 ≤ S ≤ 1
```

Интерпретация:

- `S` близко к 1 — кластеры плотные и хорошо отделены друг от друга;
- `S` около 0 — кластеры соприкасаются, границы размыты;
- `S` отрицательно — часть элементов, вероятно, отнесена не к своему кластеру.

Для кластера из одного элемента силуэт не определён и берётся равным 0;
если в разбиении меньше двух непустых кластеров, коэффициент не вычисляется
(в интерфейсе выводится прочерк).
