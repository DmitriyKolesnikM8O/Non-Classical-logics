# Задание

## 1. Тема и вариант

**Тема:** моделирование нечетких величин и кластерный анализ множества нечетких
величин.

**Вариант:** 1 — равномерное распределение (прямоугольная функция
принадлежности).

**Язык реализации:** Python. Программа состоит из независимой библиотеки и
графического пользовательского интерфейса (GUI).

## 2. Требуется разработать

1. Модель нечеткой величины с равномерным распределением:

   ```text
           ⎧ 1,  если a ≤ x ≤ b
   μ(x) =  ⎨
           ⎩ 0,  если x < a или x > b
   ```

   Величина задаётся парой граничных параметров `[a, b]`, где `a ≤ b`.

2. Операции над нечеткими величинами:

   - сложение, вычитание, умножение и деление по принципу обобщения Заде
     (интервальная арифметика);
   - сравнение (ранжирование) величин — по центру, ширине, степени
     доминирования, индексам возможности и необходимости;
   - метрики расстояния — Хаусдорфа и евклидова.

3. Генератор случайной выборки нечетких величин объёмом от 100 до 300
   элементов с воспроизводимым зерном (seed).

4. Кластерный анализ множества нечетких величин:

   - на заданное число кластеров `K` (K-Means);
   - по заданному критерию: порог внутрикластерного расстояния (полная связь),
     уровень отбора по отношению сходства (α-уровень) и плотность
     (DBSCAN-подобный алгоритм).

5. Журналирование всех действий и операций в файл-лог с метками времени.

6. Интерактивная визуализация функций принадлежности, операций и результатов
   кластеризации в графическом интерфейсе.

7. Программная документация и модульная структура, допускающая использование
   библиотеки сторонними программами.
