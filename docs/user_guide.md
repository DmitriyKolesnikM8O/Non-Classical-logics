# Руководство пользователя

Программа «Неклассические логики — нечеткие величины (вариант 1: равномерное
распределение)» — настольное приложение с графическим интерфейсом на Tkinter.
Оно позволяет:

- выполнять арифметические операции над нечеткими величинами (сложение,
  вычитание, умножение, деление) и сравнивать их;
- вычислять расстояния между величинами (метрики Хаусдорфа и евклидова);
- генерировать случайные выборки от 100 до 300 величин;
- проводить кластерный анализ четырьмя методами: K-Means на заданное число
  кластеров, по порогу, по α-уровню и по плотности;
- строить графики функций принадлежности и диаграммы кластеров;
- вести журнал всех действий в файл с метками времени.

Программа состоит из двух частей: графического интерфейса (описан в этом
документе) и независимой библиотеки `fuzzy_core`, которую можно использовать из
своего кода — ей посвящён отдельный документ «Описание архитектуры библиотек
(API)».

Типовой порядок работы: сгенерировать выборку → выполнить кластерный анализ →
посмотреть результат на графике и в журнале. Подробно по каждой вкладке —
§3–§6, полный пример работы от начала до конца — §7.

## 1. Рекомендации по развертыванию

Программа поставляется как папка с исходным кодом: отдельного инсталлятора нет.
Развёртывание — это создание виртуального окружения, установка зависимостей из
`requirements.txt` и запуск `main.py`. Все шаги выполняются один раз.

### 1.1. Требования

| Компонент | Требование |
| --- | --- |
| Операционная система | Windows 10/11 (проверено на Windows 10). На Linux/macOS программа должна работать, но не проверялась |
| Python | 3.10 или новее (проверено на 3.13.2). `tkinter` входит в стандартную поставку Windows; в Linux ставится отдельным пакетом `python3-tk` |
| Библиотеки | `numpy`, `matplotlib`, `python-docx`, `pypdf`, `pytest` — устанавливаются из `requirements.txt` |
| Диск | около 160 МБ на виртуальное окружение с библиотеками плюс исходники проекта |
| Экран | от 1280×800: окно программы занимает 1180×780 |
| Время запуска | около 1–2 с (основное время — загрузка `matplotlib`) |

Интернет нужен только при установке зависимостей; для самой работы программы он
не требуется.

### 1.2. Подготовка окружения (один раз)

В папке проекта:

```bat
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pip install -e .
```

Первая команда создаёт виртуальное окружение (`py` — штатный лаунчер Windows;
если его нет, укажите полный путь к `python.exe`), вторая ставит библиотеки
(numpy, matplotlib, python-docx, pypdf, pytest), третья устанавливает сам
проект в режиме разработки — после этого пакеты `fuzzy_core`, `logger` и `gui`
доступны из любого места.

### 1.3. Запуск

```bat
.venv\Scripts\python.exe main.py
```

Полезные ключи:

```bat
.venv\Scripts\python.exe main.py --help              справка по ключам
.venv\Scripts\python.exe main.py --log-dir D:\logs   папка для журналов
```

Откроется главное окно с четырьмя вкладками (см. §2). По умолчанию журналы
пишутся в папку `logs/` в корне проекта. Файл журнала создаётся при запуске и
называется по дате и времени, например `session_2026-10-17_15-28-53.log`.

Открыть папку с журналами можно из меню **Файл → Открыть папку журналов**,
закрыть программу — **Файл → Выход**. В меню **Справка → О программе** кратко
описано назначение программы и версия.

> Если в Windows команда `python` открывает Microsoft Store, используйте
> именно путь `.venv\Scripts\python.exe` или команду `py`.

### 1.4. Проверка после установки

**Способ 1 — автотесты** (быстро, графический интерфейс не нужен):

```bat
.venv\Scripts\python.exe -m pytest -q
```

Ожидаемый результат — `540 passed` (число тестов может расти по мере развития
проекта). Если тесты не запускаются, чаще всего не установлен сам проект —
нужен `pip install -e .` из §1.2.

**Способ 2 — проверка «руками», около минуты:**

1. запустить `main.py`;
2. вкладка «Генерация и выборка» → **Сгенерировать** (объём 100, зерно 2026);
3. вкладка «Кластерный анализ» → метод «По α-уровню», α = 0.7 →
   **Кластеризовать**;
4. в блоке «Результат» должны появиться число кластеров и строка `k(α)`.

### 1.5. Перенос, обновление и удаление

- **Перенос на другой компьютер:** скопировать папку проекта без `.venv` и
  повторить §1.2 — виртуальное окружение привязано к конкретной системе.
- **Обновление:** заменить файлы исходников и повторить
  `pip install -r requirements.txt` (если менялся список библиотек).
- **Удаление:** удалить папку проекта и, если журналы писались наружу, папку
  журналов. Отдельных записей в реестре и системных папок программа не создаёт;
  проект, установленный через `pip install -e .`, удаляется вместе с `.venv`.

## 2. Общий вид окна

Окно размером 1180×780 (по центру экрана) состоит из четырёх вкладок:

```text
Арифметика | Генерация и выборка | Кластерный анализ | Журнал
```

Внизу окна — строка состояния: слева последнее действие программы, справа путь
к текущему файлу журнала (с подписью `Журнал: …`).

Вкладки связаны между собой: выборка, сгенерированная на вкладке «Генерация и
выборка», автоматически становится доступной вкладке «Кластерный анализ». Если
выборка ещё не создана, кластерный анализ сообщит об этом и предложит сначала
её сгенерировать.

Общее правило при вводе чисел: десятичный разделитель может быть и точкой, и
запятой (`1.5` и `1,5` — одно и то же).

## 3. Вкладка «Арифметика»

Калькулятор операций над двумя нечеткими величинами `A` и `B`.

### 3.1. Что вводить

- **Исходные величины** — четыре поля: `A: от`, `до` и `B: от`, `до`.
  Это границы `[a, b]`; требуется `a ≤ b`. По умолчанию заданы `A = [1, 3]` и
  `B = [2, 5]`.
- **Операция** — четыре кнопки: `+`, `−`, `×`, `÷`.
- **Метрика расстояния** — раскрывающийся список из двух вариантов:
  `hausdorff` (по умолчанию) и `euclidean`. Метрика влияет на число в строке
  «выбрано …» при сравнении и на колонку расстояния в протоколе.
- **Кнопка «Сравнить A и B»** — сравнение величин без арифметики.

### 3.2. Что получается

После нажатия кнопки операции:

- в блоке **Результат** появляется две строки:

  ```text
  A + B = [3.000, 8.000]
  центр c = 5.500, ширина w = 5.000
  ```

- в **Протокол вычислений** добавляется подробная запись:

  ```text
  Операция Сложение (+): [1.000, 3.000] (c=2.000, w=2.000) + [2.000, 5.000]
  (c=3.500, w=3.000) = [3.000, 8.000] (c=5.500, w=5.000)
  ```
- на **графике** рисуются три функции принадлежности: `A`, `B` и результат;
- в строке состояния и в журнале фиксируется выполненное действие.

Кнопка **Очистить протокол** убирает текст протокола (журнал при этом
сохраняется: он ведётся в файле и виден на вкладке «Журнал»).

### 3.3. Сравнение величин

Кнопка «Сравнить A и B» выводит сразу весь набор характеристик:

```text
A < B  (сначала по центру c, затем по ширине w)
d_H = 2.0000,  d_E = 1.5811
выбрано расстояние Хаусдорфа = 2.0000
Pos(A ≥ B) = 1.0000
Nec(A ≥ B) = 0.0000
доминирование P(A > B) = 0.0833
```

Как это читать:

- `A < B` — результат ранжирования (сначала по центру, при равенстве — по
  ширине);
- `d_H`, `d_E` — оба расстояния между величинами, для сравнения;
- `выбрано …` — расстояние по метрике, выбранной в списке;
- `Pos(A ≥ B)` и `Nec(A ≥ B)` — индексы возможности и необходимости Заде
  (0 или 1);
- `доминирование P(A > B)` — вероятность того, что значение `A` окажется больше
  значения `B` при случайном равномерном выборе внутри носителей.

### 3.4. Деление на интервал с нулём

Если делитель содержит нуль, например `B = [-1, 1]`, программа откажется
выполнять деление и покажет красным:

```text
Ошибка: Деление невозможно: интервал делителя [-1, 1] содержит 0
```

Ошибка попадает в протокол и в журнал; исходные данные не теряются — можно
исправить `B` и повторить операцию.

## 4. Вкладка «Генерация и выборка»

Здесь создаётся случайная выборка нечетких величин.

### 4.1. Параметры выборки

| Поле | Смысл | Значение по умолчанию |
| --- | --- | --- |
| Границы `a` (от / до) | диапазон левой границы | −10 … 10 |
| Ширина `w = b − a` (от / до) | диапазон ширины | 0 … 4 |
| Объём выборки `N` (от / до) | сколько величин создать | 100 … 300 |
| Зерно генератора (`seed`) | воспроизводимость | пусто — случайное |

Правая граница каждой величины вычисляется автоматически как `b = a + w`,
поэтому условие `a ≤ b` выполняется всегда.

Если задать **зерно**, выборка полностью воспроизводима: такое же зерно даст
такой же набор. Если оставить поле пустым, зерно будет выбрано случайно и
записано в журнал — по журналу эксперимент всегда можно повторить.

### 4.2. Кнопки

- **Сгенерировать** — создать выборку по заданным параметрам.
- **Очистить** — убрать выборку и таблицу, освободить вкладку кластерного
  анализа.

### 4.3. Результат

В блоке **Результат** показывается сводка вида:

```text
Сгенерировано величин: 150
seed = 2026
a ∈ [-10, 10], w ∈ [0, 4]
средний центр = 1.245, средняя ширина = 2.078
охватывающий интервал = [-9.949, 13.108]
```

Справа — таблица **Список величин** со столбцами `№`, `a`, `b`, `центр c`,
`ширина w`; таблица прокручивается полосой и колесом мыши.

Пример выше получен при параметрах по умолчанию и зерне `2026`; при другом
зерне числа будут иными.

## 5. Вкладка «Кластерный анализ»

Самый содержательный раздел программы. Работа ведётся в два шага: сначала
создать выборку на вкладке «Генерация и выборка», затем выполнить анализ здесь.

### 5.1. Левый столбец: настройки

- **Данные** — сколько величин доступно и кнопка **Обновить** (перечитать
  сведения о выборке, если она только что изменена).
- **Метод** — четыре переключателя:
  - `K-Means: на K кластеров` — число кластеров задаётся вручную;
  - `По порогу (полная связь)` — число кластеров определяется данными и порогом;
  - `По α-уровню (уровень отбора)` — число кластеров определяется уровнем α
    по шкале сходства: чем выше уровень, тем больше кластеров;
  - `По плотности (DBSCAN-подобный)` — кластеры выделяются по плотности, часть
    точек может быть признана шумом.
- **Метрика и зерно** — список метрик (`hausdorff` / `euclidean`) и поле зерна
  (влияет на инициализацию K-Means; у остальных методов не используется).
- **Параметры метода** — поля меняются в зависимости от выбранного метода:

  | Метод | Поля |
  | --- | --- |
  | K-Means | `K` — число кластеров (по умолчанию 3) |
  | По порогу | `порог` — максимальное допустимое расстояние внутри кластера (1.0) |
  | По α-уровню | `α` — уровень отбора (0.7), `связь для α` — `полная` или `одиночная` |
  | По плотности | `eps` — радиус окрестности (0.5), `minPts` — минимум точек в окрестности (2) |

  Поля, не относящиеся к выбранному методу, заблокированы (серые); поле зерна
  активно только для K-Means, список `связь для α` — только для α-уровня.

- **Ползунок α** (под полями параметров) — есть только у метода «По α-уровню».
  Потяните его: число кластеров на диаграмме, таблицы, сводка, кривая `k(α)` и
  матрица сходства пересчитываются **на лету**, без нажатия «Кластеризовать».
  Рядом показано текущее значение (`α = 0.70`), а кнопка `▶` запускает
  «проигрывание» уровней от `1.0` до `0.1` — видно, как кластеры дробятся и
  сливаются. В журнал живая перестройка не пишется: записи остаются только от
  явного нажатия **Кластеризовать** и от ошибок. Значение α дублируется в поле
  `α` в параметрах метода — можно ввести число точно.

- **Пошаговая агломерация** (под кнопкой «Кластеризовать») — счётчик `шаг i/n`,
  кнопки `Шаг` / `▶` / `↺` и ползунок скорости для метода «По порогу (полная
  связь)»; подробнее — в §5.3. У остальных методов эти элементы заблокированы.

- Кнопка **Кластеризовать** — выполнить анализ.
- **Результат** — сводка по последнему запуску:
  число кластеров и шумовых точек, размеры кластеров, средняя внутрикластерная
  дисперсия, максимальный диаметр и коэффициент силуэта (`silhouette`).

  Если кластеров много, список размеров обрезается: `1, 1, 1, …, (всего 92)`.

  Коэффициент `silhouette` (оценка качества разделения) считается при нажатии
  **Кластеризовать**. При пересчёте ползунком α он не вычисляется — это заметно
  ускоряет живое движение, а в сводке появляется подсказка
  `silhouette — (нажмите «Кластеризовать»)`.

  Для метода «По α-уровню» в сводку добавляется строка `k(α)` — сколько
  кластеров получилось бы на каждом уровне:

  ```text
  k(α): 1.0→150, 0.9→20, 0.8→8, 0.7→5, 0.5→3, 0.3→2
  ```


### 5.2. Правая часть: график и таблицы

Сверху — кнопка **Легенда** и три представления результата на вкладках
(переключаются закладками над графиком). «Профиль k(α)» и «Матрица сходства»
относятся к методу **По α-уровню**: у остальных методов эти закладки
неактивны (серые) — открыть их нельзя:

- **Диаграмма** — привычная диаграмма рассеяния: по горизонтали центр `c`,
  по вертикали ширина `w`; точки окрашены по номерам кластеров, серые точки —
  шум, чёрные ромбы — центры кластеров;
- **Профиль k(α)** — ступенчатая кривая зависимости числа кластеров от уровня
  отбора; вертикальная пунктирная линия отмечает текущий α. Ступеньки наглядно
  показывают уровни, на которых разбиение скачком меняется (для не-α-методов
  вкладка пуста);
- **Матрица сходства** — тепловая карта матрицы `r_ij`: строки и столбцы
  упорядочены по кластерам, поэтому кластеры видны как блоки вдоль диагонали,
  а клетки со сходством `r_ij ≥ α` подсвечены оранжевым. Чем строже уровень,
  тем мельче блоки. Шкала сходства — от 0 до 1 (указана в углу карты).

При живой перестройке по ползунку α перерисовывается только **открытая** вкладка
(так движение остаётся плавным); остальные обновляются сами, как только вы на них
переключитесь.

Ниже — две таблицы:

- **Кластеры**: `кластер`, `размер`, `центр c`, `центр w`, `диаметр`,
  `дисперсия`;
- **Точки**: `№`, `a`, `b`, `центр c`, `ширина w`, `кластер` (для шума в
  последнем столбце написано `шум`).

Между графиком, легендой и таблицами есть **раздвижные разделители**: ухватите
мышью границу между областями и потяните, чтобы отдать нужной части больше
места. Увеличить окно тоже можно — всё подстраивается.

### 5.3. Пошаговая агломерация

Метод **По порогу (полная связь)** умеет показывать сам процесс кластеризации
по шагам. В блоке **Пошаговая агломерация** (под кнопкой «Кластеризовать») есть
счётчик `шаг i/n`, кнопка **Шаг**, кнопка проигрывания `▶/■` и кнопка сброса `↺`.
Кнопки активны только у этого метода; у остальных они заблокированы (серые).

1. Выберите метод **По порогу (полная связь)**. Текущее значение порога на ход
   шагов не влияет — последовательность слияний определяется только данными.
2. Нажмите **Шаг** — выполнится одно слияние самых близких кластеров. Счётчик
   покажет `шаг 1/n`, диаграмма, таблицы и сводка обновятся под новое
   разбиение (открытая панель легенды — тоже), а в журнал попадёт строка вида
   `Агломерация, шаг 1: слияние кластеров размерами 1 и 1 на расстоянии 0.0137`.
3. Нажимайте **Шаг** дальше: число кластеров каждый раз уменьшается на один —
   видно, как мелкие группы объединяются во всё более крупные.
4. Кнопка `▶` «проигрывает» шаги автоматически; повторное нажатие (`■`)
   останавливает. По умолчанию включена галочка **останавливаться на пороге** —
   тогда финал совпадает с кнопкой «Кластеризовать» (например, при пороге 1.0
   шагов будет 181 из 246, а кластеров — 66). Снимите галочку, если хотите
   довести процесс до одного кластера (`246/246`).
5. Ползунок **скорость** под кнопками задаёт темп проигрывания — от 1 до 20
   шагов в секунду. Его можно двигать **прямо во время проигрывания**: новый
   темп применяется сразу. На максимальной скорости 264 слияния проходят
   примерно за полминуты вместо нескольких минут.
6. Кнопка `↺` (**Сброс**) возвращает к началу: все величины — отдельные точки
   (нарисованы серым, кластеров ещё нет).

Число шагов равно `n − 1`, где `n` — размер выборки: полная последовательность
слияний полной связи и есть дендрограмма (см. теоретический раздел). Просмотр
по шагам помогает понять, на каких расстояниях кластеры объединяются, и подобрать
подходящий порог. При большом числе кластеров точки рисуются одной серией с
цветом на каждую точку, а панель легенды собирается только когда открыта, —
поэтому смена шага остаётся быстрой.

**Галочка «останавливаться на пороге»** (включена по умолчанию) привязывает
конец анимации к текущему значению порога метода «по порогу». Так финал
пошаговой агломерации всегда совпадает с результатом кнопки «Кластеризовать».
Если снять галочку, проигрывание пройдёт весь путь до одного кластера.
Во время автоматического проигрывания таблицы и легенда не пересобираются на
каждом шаге (это самая дорогая часть отрисовки): они обновляются один раз,
когда проигрывание останавливается или доходит до конца.

### 5.4. Легенда

Если кластеров больше десяти, подписи не рисуются на самом графике (они
закрыли бы его) — они собраны в отдельной панели:

1. после расчёта кнопка показывает `Показать легенду (число_кластеров)`;
2. нажмите её — справа от графика откроется панель со строками вида
   `[цвет] кластер 7` и пояснением `точек: 4, c=-0.12, w=1.05`;
3. список прокручивается полосой справа или колесом мыши (курсор должен быть
   над списком);
4. повторное нажатие (`Скрыть легенду`) убирает панель; при новом расчёте
   открытая легенда обновляется сама. Скрытая панель не пересобирается (это
   экономит время при десятках кластеров) — при открытии она сразу покажет
   свежие данные.

Каждому кластеру соответствует свой цвет; у соседних по номеру кластеров цвета
максимально различаются.

### 5.5. Как выбирать параметры

Ориентиром служат числа, полученные на типовой выборке из 150 величин (зерно
`2026`, метрика Хаусдорфа). Для других выборок значения будут близкими, но не
совпадут.

- **K-Means**: начните с `K` от 3 до 8. Смотрите на коэффициент силуэта: чем
  ближе к 1, тем лучше разделение; около 0 и ниже — кластеры пересекаются или
  `K` выбрано неудачно. Для этой выборки при `K = 5` силуэт равен 0.51 —
  приемлемое разделение.
- **По порогу** (порог — максимальное допустимое расстояние внутри кластера):

  ```text
  Порог  2 → около 28 кластеров   Порог  5 → около  8 кластеров
  Порог  3 → около 17 кластеров   Порог  6 → около  6 кластеров
  Порог  4 → около 10 кластеров   Порог  8 → около  4 кластеров
  ```

  Малое значение (0.1–0.5) даёт десятки мелких кластеров, вплоть до отдельных
  величин.
- **По плотности**: `eps` — радиус окрестности (порядка среднего расстояния
  между «соседями»), `min точек` — сколько точек должно быть в окрестности,
  чтобы считать её плотной.

  ```text
  eps = 0.5, min точек = 3 → около 21 кластера, 55 точек признаны шумом
  eps = 1.0, min точек = 3 → около  5 кластеров, шум почти отсутствует
  eps = 1.5, min точек = 3 → всё сливается в один кластер
  ```

  Поэтому начинает разумно с `eps` около 1.0 и `min точек` 2–3, а затем
  подстраивать их под нужную детализацию.

- **По α-уровню** (уровень — безразмерная величина из `(0, 1]` по шкале
  сходства; `связь = полная` — разрез дендрограммы, `одиночная` — канонический
  α-срез отношения):

  ```text
  α = 1.0 → 150 кластеров (только совпадающие величины)
  α = 0.9 →  20 кластеров
  α = 0.8 →   8 кластеров
  α = 0.7 →   5 кластеров
  α = 0.5 →   3 кластера
  α = 0.3 →   2 кластера
  ```

  Зависимость монотонная: чем выше уровень, тем больше кластеров. Разумный
  диапазон — 0.6–0.9. С `связь = одиночная` на плотной выборке почти всё
  сливается уже при α ≈ 0.95 — это ожидаемое свойство одиночной связи, поэтому
  по умолчанию выбрана полная.

### 5.6. Ошибки

| Сообщение | Что случилось |
| --- | --- |
| `выборка пуста — сначала сгенерируйте её на вкладке «Генерация и выборка»` | анализ запущен без данных |
| `k должно удовлетворять 1 <= k <= 150, получено 200` | `K` больше числа величин |
| `K: число кластеров должно быть целым, получено 2.5` | в поле `K` дробное число |
| `eps должен быть больше нуля, получено 0.0` | задан нулевой радиус |
| `minPts: минимальное число точек должно быть целым, получено 2.5` | в поле `minPts` дробное число |
| `не задано поле «порог»` | пустое поле параметра |
| `α-уровень должен лежать в (0, 1], получено 1.5` | α вне допустимого диапазона |

Ошибка показывается красным в блоке «Результат», записывается в протокол и в
журнал; таблицы и график при этом очищаются, чтобы не показывать устаревшие
данные.

## 6. Вкладка «Журнал»

Показывает текущий файл журнала сессии целиком.

- **Обновить** — перечитать файл с диска.
- **Автообновление (2 с)** — переключатель: пока он включён, журнал
  перечитывается каждые 2 секунды.
- **Фильтр** — строка поиска: показываются только строки, содержащие указанный
  текст. Поиск запускается кнопкой **Найти** или клавишей Enter; пустой фильтр
  возвращает весь журнал.
- **Сохранить как…** — скопировать журнал в выбранный файл (по умолчанию
  предлагается имя текущего журнала с расширением `.log`).

Под кнопками — информационная строка: путь к файлу журнала, общее число строк и
число показанных строк с учётом фильтра, время последнего обновления и путь к
последней сохранённой копии.

Что записывается в журнал:

- запуск и завершение сессии, версия программы;
- созданные величины и результаты арифметических операций;
- сравнения величин (метрики, индексы Заде, доминирование);
- параметры и результаты генерации выборки;
- параметры и пошаговые результаты кластеризации: метод, метрика, число
  элементов, число и размеры кластеров, центроиды, диаметры, инерция,
  коэффициент силуэта;
- сообщения об ошибках с указанием, в какой операции они возникли.

Формат журнала — обычный текст с временными метками, поэтому его можно
открывать любым текстовым редактором.

## 7. Полный пример работы

1. Запустите программу: `.venv\Scripts\python.exe main.py`.
2. Перейдите на вкладку **Генерация и выборка**, задайте объём `N` от 150 до
   150 и зерно `2026`, нажмите **Сгенерировать**. В сводке появится
   «Сгенерировано величин: 150», в таблице — 150 строк.
3. Перейдите на вкладку **Кластерный анализ**. В блоке «Данные» будет написано
   «Доступна выборка: 150 величин».
4. Выберите метод `K-Means: на K кластеров`, метрику `hausdorff`, задайте
   `K = 5` и зерно `2026`, нажмите **Кластеризовать**.
5. Прочитайте сводку — например, такую:

   ```text
   Кластеров: 5, шумовых точек: 0
   размеры: 23, 23, 31, 30, 43
   средняя внутрикластерная дисперсия = 1.2453
   максимальный диаметр = 6.4057
   silhouette = 0.5078
   ```
6. Изучите диаграмму: чёрные ромбы — центры кластеров, точки раскрашены по
   кластерам. Откройте таблицу «Точки», чтобы увидеть, к какому кластеру
   отнесена конкретная величина.
7. Поставьте метод `По порогу (полная связь)`, порог `2.0`, снова нажмите
   **Кластеризовать** — сравните результат с K-Means.
8. Поставьте метод `По плотности`, `eps = 0.5`, `min точек = 3` — часть точек
   может стать шумом (серый цвет, «шум» в таблице).
9. Перейдите на вкладку **Журнал**, включите фильтр (например, `Кластеризация`)
   и посмотрите записи обо всех шагах, затем нажмите **Сохранить как…** и
   сохраните журнал рядом с отчётом.

## 8. Частые вопросы

**Почему на графике нет подписей кластеров?**
Их больше десяти, поэтому легенда вынесена в отдельную панель — нажмите кнопку
«Показать легенду (N)» над графиком.

**Почему точки серые?**
Это шум: плотностная кластеризация не отнесла их ни к одному кластеру.
Увеличьте `eps` или уменьшите `min точек`, и они, скорее всего, попадут в
кластеры.

**Кластеров получилось слишком много (или один).**
Для метода «По порогу» измените порог: он задаёт максимальное расстояние внутри
кластера. Для метода «По плотности» подстройте `eps`.

**Результаты разные при одном и том же наборе данных.**
Так бывает у K-Means: разбиение зависит от начальной инициализации. Задайте
зерно — результат станет воспроизводимым.

**Изменения не видны в журнале на вкладке «Журнал».**
Нажмите **Обновить** или включите **Автообновление (2 с)**.

**Как получить тот же набор величин ещё раз?**
На вкладке «Генерация и выборка» укажите то же зерно, что записано в журнале, —
выборка воспроизведётся полностью.
