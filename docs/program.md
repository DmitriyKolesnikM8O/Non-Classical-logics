# Описание программы

## 1. Общая схема

Программа состоит из трёх независимых пакетов и точки входа:

```text
main.py                  запуск графического интерфейса
src/fuzzy_core/          библиотека нечетких вычислений и кластеризации
src/logger/              журналирование действий в файл
src/gui/                 графический интерфейс (Tkinter + matplotlib)
```

Пакеты `fuzzy_core` и `logger` не зависят от интерфейса: их можно использовать
в сторонних программах (см. раздел «Описание программного интерфейса (API)»).
Пакет `gui` использует оба пакета и не содержит собственной математики —
только ввод данных, вызовы библиотеки и отображение результата.

Проект оформлен по схеме `src-layout` (`pyproject.toml`, пакеты в `src/`),
поэтому после команды `pip install -e .` пакеты доступны как обычные модули
Python.

## 2. Библиотека `fuzzy_core`

### 2.1. Модуль `fuzzy_variable.py`

Основной класс — `UniformFuzzyVariable`. Он хранит границы `a` и `b`, проверяет
условие `a ≤ b` и предоставляет:

- функцию принадлежности `membership(x)` / `mu(x)` и вызов `A(x)`;
- α-срез `alpha_cut(alpha)`, носитель `support`, ядро `core`;
- характеристики `center` (центр `c`) и `width` (ширина `w`);
- арифметику через операторы `+`, `-`, `*`, `/` (и унарный минус);
- расстояния `hausdorff_distance`, `euclidean_distance`, `distance(metric)`;
- сравнение: `compare`, `dominance`, `possibility_greater_or_equal`,
  `necessity_greater_or_equal`, ключ сортировки `rank_key`;
- конструктор `from_center_width(c, w)` — обратный переход от центра и ширины
  к границам.

В этом же модуле лежат свободные функции `alpha_cut_trapezoid` и
`alpha_cut_triangular` — общие формулы α-среза для трапеции и треугольника
(равномерная величина является их вырожденным случаем).

### 2.2. Модуль `fuzzy_set.py`

Класс `FuzzySet` — упорядоченная коллекция нечетких величин. Поддерживает
длину, индексацию, итерацию, добавление величин и служит единицей обмена
данными между вкладками интерфейса: генератор создаёт `FuzzySet`, а
кластеризация и визуализация его читают.

### 2.3. Модуль `generator.py`

Функции `generate_variables` и `generate_sample` создают случайную выборку
объёмом от `MIN_COUNT = 100` до `MAX_COUNT = 300`. Параметры генератора:

- диапазон левой границы `a` (`a_range`);
- диапазон ширин `w = b − a` (`width_range`);
- количество величин (`count`);
- зерно генератора (`seed`) — при повторном запуске с тем же зерном выборка
  воспроизводится полностью.

### 2.4. Модуль `clustering.py`

Реализованы четыре метода кластеризации:

| Метод | Функция | Параметры |
| --- | --- | --- |
| K-Means | `kmeans` | число кластеров `K`, метрика, зерно |
| По порогу (полная связь) | `threshold_clustering` | порог внутрикластерного расстояния |
| По α-уровню | `alpha_cut_clustering` | уровень отбора `α`, тип связи, замыкание |
| По плотности | `density_clustering` | `eps`, `min_points` |

Результат метода — объект `ClusterResult`: список кластеров `Cluster` (состав,
центроид, размер, диаметр, инерция и дисперсия центров), метки всех точек и
отдельный список шумовых точек. Для оценки качества вычисляется коэффициент
силуэта.

Вспомогательные классы для интерактивной работы:

- `Agglomeration` — последовательность слияний агломеративной кластеризации:
  хранит шаги `Merge`, умеет выдать разбиение после любого шага и построить
  профиль `k(α)`;
- `AlphaClusterer` — движок α-уровня: кэширует матрицу сходства, замыкание и
  профиль, чтобы ползунок α пересчитывался быстро;
- `similarity_matrix` и `max_min_closure` — матрица сходства и её max-min
  замыкание.

## 3. Подсистема журналирования

Класс `SessionLogger` создаёт файл `logs/session_<дата>_<время>.log` и пишет
строки с метками времени. Журналируются:

- генерация выборки и её параметры;
- арифметические операции, сравнения и ошибки ввода;
- запуск кластеризации, выбранный метод, метрика и параметры;
- шаги пошаговой агломерации и изменения α.

Каталог журналов можно изменить ключом запуска `--log-dir` или открыть из меню
«Файл → Открыть папку журналов».

## 4. Графический интерфейс

Главное окно (`FuzzyApp`) содержит строку меню, панель вкладок и строку
состояния. Вкладки:

1. **«Арифметика»** — ввод двух величин `A` и `B`, выбор операции, результат,
   сравнение, протокол вычислений и график функций принадлежности.
2. **«Генерация и выборка»** — параметры генератора, таблица величин, сводка
   выборки.
3. **«Кластерный анализ»** — выбор метода и метрики, параметры, запуск,
   пошаговая агломерация, ползунок α, таблицы кластеров и точек, график
   рассеяния (`c`, `w`), профиль `k(α)` и тепловая карта матрицы сходства.
4. **«Журнал»** — просмотр текущего лога и переход к каталогу журналов.

Данные между вкладками передаются через главное окно: сгенерированная выборка
хранится в `FuzzyApp.sample`, результат кластеризации — в
`FuzzyApp.clustering_result`. Вкладка кластеризации при активации сама
подхватывает свежую выборку.

Графики строит модуль `gui/plotter.py` (`MembershipPlot`) через
`matplotlib.figure.Figure` и `FigureCanvasTkAgg` — без глобального состояния
`pyplot`. Это позволяет держать несколько независимых графиков в одном окне
и корректно использовать matplotlib внутри Tkinter.

## 5. Поток данных

```text
параметры генератора
        │
        ▼
generate_sample() ──► FuzzySet ──► таблица и сводка
        │
        ├──► вкладка «Арифметика» (A, B — отдельные величины)
        │
        ▼
метод, метрика, параметры
        │
        ▼
kmeans / threshold_clustering / alpha_cut_clustering / density_clustering
        │
        ▼
ClusterResult ──► таблицы кластеров и точек
        │
        ▼
MembershipPlot: диаграмма (c, w), профиль k(α), матрица сходства
        │
        ▼
SessionLogger: строки журнала
```

## 6. Тестирование

Автоматические тесты лежат в каталоге `tests` и запускаются командой
`pytest`. Они покрывают:

- свойства и арифметику величин, граничные случаи (деление на ноль,
  отрицательные интервалы);
- генератор: диапазон объёма, воспроизводимость по зерну, выполнение `a ≤ b`;
- все четыре метода кластеризации, пошаговую агломерацию, профиль `k(α)`,
  метрики качества;
- журналирование;
- вкладки интерфейса, отрисовку графиков и раскладку элементов;
- сборку документации из Markdown в DOCX.

## 7. Ограничения

- Программа хранит выборку только в памяти; сохранения выборки в файл нет
  (журнал фиксирует параметры и результаты, но не сами объекты).
- Кластеризация выполняется в одном потоке; на выборке 300 величин шаг
  агломерации занимает десятые доли секунды.
- Графический интерфейс рассчитан на настольную ОС с Tkinter; на сервере без
  дисплея работает только библиотека `fuzzy_core`.
